# 독도 코리아 스쿨 — 운영 안내

## 폴더 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 본체. 문항 내장 사본을 함께 가지고 있습니다. |
| `questions.json` | 문항 원본. 평소 고치는 곳은 여기 하나입니다. |
| `music/` | 배경음악. `bgm1.mp3`부터 순서대로 재생합니다. |
| `og.png` | 카톡·유튜브 링크 미리보기 이미지. |
| `vercel.json` | 캐시 설정. 문항을 올리면 바로 반영되게 합니다. |
| `validate.py` | 문항 형식 검사기. 올리기 전에 돌립니다. |
| `tools_ox_check.py` | OX 치환 검사기. 조사·중복을 잡습니다. |

앱은 내장 사본으로 먼저 켜지고, 곧바로 `questions.json`을 읽어 판 번호가 다르면 그쪽으로 갈아탑니다.
그래서 `questions.json`이 없거나 깨져도 앱은 멈추지 않습니다.

## 문항을 고칠 때

1. `questions.json`을 엽니다.
2. 문항을 고칩니다.
3. 맨 위 `version` 값을 반드시 바꿉니다. 예: `2026-09-05.1` → `2026-09-05.2`
   이 값이 그대로면 앱은 갱신하지 않습니다.
4. `count`도 문항 수에 맞춥니다.
5. 검사기를 돌립니다: `python3 validate.py questions.json`
   오류 0건이어야 합니다. 경고는 올려도 됩니다.
6. OX 검사기도 돌립니다: `python3 tools_ox_check.py`
7. GitHub에서 `questions.json`만 교체합니다. Vercel이 자동으로 다시 배포합니다.
8. 앱을 열어 홈 화면 맨 아래 판 번호가 바뀌었는지 확인합니다.

`index.html`은 앱 기능을 바꿀 때만 건드립니다. 문항만 고칠 때는 손대지 않습니다.

## 반드시 지킬 것

id는 절대 재사용하지 마십시오.
사용자의 진도·복습 일정·섬의 불빛이 모두 문항 id로 저장되어 있습니다.
지운 id를 다른 문항에 다시 쓰면 남의 기록이 엉뚱한 문항에 붙습니다.
문항을 지우실 때는 그냥 빼시면 되고, 남아 있던 기록은 자동으로 무시됩니다.

신규 문항의 `rate`는 반드시 `null`입니다. 정답률을 임의로 적지 마십시오.
`rate`는 문항 배점을 정하는 값이라, 없는 숫자를 넣으면 점수 체계가 흔들립니다.

학년 코드는 21개만 씁니다.
`K E1 E2 E3 E4 E5 E6 M1 M2 M3 H1 H2 H3 U1 U2 U3 U4 MA1 MA2 PHD1 PHD2`
`U` `MA` `PHD` `RES` `PROF`는 옛 코드라 쓰지 않습니다.

`atype`이 `개별보기_교차추출금지`인 문항은 `blankDistractors` 3개가 필수입니다.
없으면 앱이 빈칸 출제를 건너뛰고 4지선다로만 냅니다.

## 문항을 추가하면 생기는 일

해당 학년의 총점이 올라가므로 기존 이용자의 "진급까지 남은 점수"가 늘어납니다.
이미 맞힌 문항의 점수는 그대로 유지되니 손해는 아닙니다.
한 학년을 한꺼번에 채우기보다 나눠 올리시는 편이 이용자 체감이 낫습니다.

정답 위치나 보기 문구를 바꾸는 것은 기존 기록에 영향이 없습니다.

## 화면이 갱신되지 않을 때

홈 화면 맨 아래 판 번호를 먼저 보십시오.
옛 번호가 보이면 `questions.json`의 `version`을 안 바꿨거나, 파일이 아직 안 올라간 것입니다.
주소 끝에 `#reset`을 붙여 열면 기록 없이 처음부터 확인할 수 있습니다.

## 배포 전 점검

- `python3 validate.py questions.json` 오류 0건
- 휴대폰에서 실제로 열어 수업 5문항 풀기
- 결과 카드 저장과 공유 버튼 동작 확인
- 카카오톡에 링크를 붙여 미리보기 카드가 뜨는지 확인 (`og:image` 파일 필요)

## 배경음악 바꾸기

`music/` 폴더의 `bgm1.mp3`, `bgm2.mp3`, `bgm3.mp3`를 교체하시면 됩니다.
곡 수를 바꾸시려면 `index.html` 안의 `const BGM=[...]` 목록을 함께 고쳐야 합니다.

곡은 기본적으로 재생되지 않습니다. 이용자가 상단 스피커를 눌러야 내려받아 재생됩니다.
소리 나는 자동 재생은 모든 브라우저가 막기 때문이고, 데이터를 아끼는 효과도 있습니다.

## 인트로 영상 바꾸기

`index.html` 안의 `const INTRO_IDS=[...]`에 유튜브 영상 ID를 넣습니다.
주소가 `https://youtu.be/AbCdEf12345`라면 `AbCdEf12345`가 ID입니다.
여러 개를 넣으면 무작위로 하나가 재생됩니다. 첫 방문에만 나오고 두 번째부터는 건너뜁니다.

## 링크 미리보기가 회색으로 뜰 때

`og.png`가 저장소에 있는지 확인하십시오. 이 파일이 없으면 카톡에서 회색 상자만 뜹니다.
이미지를 바꾸셨다면 카카오톡은 한동안 이전 이미지를 기억합니다.
카카오 디버거(https://developers.kakao.com/tool/clear/og)에서 주소를 넣고 초기화하시면 됩니다.
